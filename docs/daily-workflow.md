# Example caller prompt

Verify the signed-in Fomo account, then run daily with at most 3 candidates, 5 rows per section and native Min size $10,000. Inspect partial/errors, freshness and output truncation. Open at most two position details when a thesis preview needs context. Do not read all historical theses. Request at most two chart images only when useful.

Write a concise research report: candidates, why selected, relevant followed holders, attributed thesis/counterargument, liquidity/concentration observations, missing evidence and what to watch next. Separate source assertions from facts; account value is not proven skill. Include Fomo links and observation time.

No trades, messages, follows or watchlist changes unless separately requested. If login or UI fails, report the failure and stop; do not infer no opportunities. Save locally unless the user configured delivery. The host chooses schedule, model and destination. This package creates no hidden schedule.
