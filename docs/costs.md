# Cost model

No LLM client is present in the adapter. Playwright executes predefined browser actions; CLI/MCP returns bounded JSON. Caller prompts, tool schemas, returned text, reasoning and charts still consume tokens. Development, UI maintenance and authentication recovery can be expensive.

A warm Windows `daily` run on September 6, 2026 with two candidates and three rows per section took about 6.1 seconds, with no per-candidate errors. An earlier repeat of a $100K thesis sample recognized all four previously observed fingerprints. These are individual samples, not guarantees or a token-savings benchmark.

The ceiling is 14,000 characters, not tokens. Evidence pages and images add input. Delta still returns metadata; it avoids repeated thesis bodies. Smaller samples reduce coverage.

For a fair comparison, run this adapter and a general browser agent against equal account, time window, views, filters, row limits and final-answer requirements. Record model, input/output/cached tokens, retries, latency, failures and coverage. Compare total cost including recovery. No controlled comparison has yet been run. Do not advertise an invented savings percentage.
